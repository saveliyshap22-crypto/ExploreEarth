# Участие в разработке

1. Создайте отдельную ветку.
2. Не добавляйте API-ключи, модели и пользовательские изображения.
3. Сохраняйте границы проектов: бизнес-модели в `Core`, внешние реализации в `AI`, `Map` или `Infrastructure`.
4. Перед pull request выполните `dotnet test EarthExplorer.sln -c Release`.
5. Для новой модели укажите источник весов, размер, SHA-256 и лицензию.
6. Не добавляйте функции распознавания личности, поиска частного адреса или скрытого отслеживания.
