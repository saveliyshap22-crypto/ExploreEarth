# ExploreEarth

Нативное Windows-приложение для исследования карты Земли, поиска мест и аккуратного определения примерного места съёмки по фотографии.

Это не сайт: интерфейс написан на C#/WPF и запускается обычным `ExploreEarth.exe`. Python, Electron и локальный веб-сервер не требуются.

## Что уже работает

- карта мира OpenStreetMap с перемещением и масштабированием;
- поиск городов, адресов и достопримечательностей;
- ввод координат `48.8584, 2.2945` и DMS;
- координаты под курсором и в центре карты;
- метка найденного места;
- светлая и тёмная тема;
- выбор или drag-and-drop фотографии;
- полностью локальное чтение EXIF, включая GPS;
- публикация self-contained `win-x64`;
- автоматическая сборка и тесты на Windows.

OCR и визуальная геолокация пока не притворяются готовыми: они находятся в следующем этапе. Точный статус есть в [дорожной карте](docs/ROADMAP.md).

## Системные требования

- Windows 10/11 x64;
- для framework-dependent сборки — .NET 10 Desktop Runtime;
- для self-contained сборки Runtime отдельно не нужен;
- интернет для карты и текстового поиска;
- RTX 3070 не нужна для текущего EXIF-этапа, но будет использоваться локальными ONNX-моделями.

## Сборка

Установите .NET 10 SDK и workload **.NET desktop development** в Visual Studio.

```powershell
dotnet restore .\EarthExplorer.sln
dotnet build .\EarthExplorer.sln -c Debug
dotnet test .\EarthExplorer.sln -c Release
dotnet run --project .\src\EarthExplorer.App\EarthExplorer.App.csproj
```

Framework-dependent публикация:

```powershell
.\build-release.ps1 -Runtime win-x64 -FrameworkDependent
```

Self-contained публикация:

```powershell
.\build-release.ps1 -Runtime win-x64
```

ARM64:

```powershell
.\build-release.ps1 -Runtime win-arm64
```

Результат появится в `dist\<runtime>`. Single-file пока отключён: Mapsui/SkiaSharp поставляет нативные библиотеки, и обычная папка публикации надёжнее одного упакованного файла.

## Карта и поиск

Карта использует Mapsui и тайлы OpenStreetMap с атрибуцией. Геокодирование выполняет Nominatim. Публичный Nominatim ограничен и не предназначен для автодополнения; клиент отправляет не более одного запроса в секунду и кэширует результаты. Для публичного релиза нужно выбрать собственный или коммерческий endpoint.

Спутникового слоя сейчас нет: он будет добавлен только с официально разрешённым провайдером. Закрытые тайлы и обход ограничений не используются.

## Приватность

- EXIF читается локально;
- оригинальная фотография не изменяется;
- фотография не отправляется в сеть;
- настоящие ключи не хранятся в репозитории;
- приложение нельзя использовать для преследования, поиска частного адреса человека, распознавания личности или скрытого отслеживания.

Анализируйте только изображения, на обработку которых у вас есть право.

## Известные ограничения

- OCR и визуальная модель ещё не подключены;
- история, метки и настройки SQLite относятся к этапу 5;
- публичные OSM/Nominatim-сервисы нельзя использовать для массовых запросов;
- WPF собирается только на Windows; поэтому репозиторий содержит Windows CI.
