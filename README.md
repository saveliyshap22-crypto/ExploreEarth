# ExploreEarth

Нативное Windows-приложение для исследования Земли, поиска мест, просмотра открытых уличных панорам и аккуратного определения примерного места съёмки по фотографии.

Это не сайт: основной интерфейс написан на C#/WPF и запускается обычным `ExploreEarth.exe`. Python, Electron и локальный веб-сервер не требуются. Встроенные 3D Земля и панорамы отображаются через Microsoft WebView2.

## Возможности версии 1.0

- обычная и топографическая 2D-карта;
- интерактивная 3D Земля с атмосферой, освещением, вращением и приближением;
- поиск городов, адресов и достопримечательностей;
- ввод координат `48.8584, 2.2945` и DMS;
- координаты под курсором и в центре карты;
- перетаскиваемый жёлтый человечек для выбора точки уличного просмотра;
- открытые фотографии и панорамы Panoramax внутри приложения;
- GeoGuessr с реальными уличными изображениями, метками, расстоянием и счётом до 5000 очков;
- светлая и тёмная тема;
- выбор или drag-and-drop фотографии;
- полностью локальное чтение EXIF, включая GPS;
- локальный OCR русского и английского текста;
- до трёх честных гипотез места по EXIF или распознанным надписям;
- готовый установщик и portable self-contained `win-x64`;
- автоматическая сборка, тесты и проверка релизных файлов на Windows.

Текущий AI-конвейер — это EXIF → локальный Tesseract OCR → поиск распознанных названий через Nominatim. Он не выдаёт гипотезу за точный адрес. Визуальная модель, способная анализировать архитектуру и ландшафт без текста, остаётся следующим этапом.

## Скачать и запустить

Откройте [последний GitHub Release](https://github.com/saveliyshap22-crypto/ExploreEarth/releases/latest) и скачайте один из файлов:

- `ExploreEarth-1.0.0-Setup-win-x64.exe` — рекомендуемый установщик; ставит приложение, OCR-модели и при необходимости Microsoft Visual C++ Runtime и WebView2 Runtime;
- `ExploreEarth-1.0.0-portable-win-x64.zip` — распакуйте папку и запустите `ExploreEarth.exe` без установки.

.NET отдельно устанавливать не нужно: обе сборки self-contained. В portable-папке есть `Install-Prerequisites.cmd` на случай, если на компьютере отсутствуют VC++ Runtime или WebView2 Runtime. Windows может показать SmartScreen, пока установщик не подписан коммерческим сертификатом.

## Системные требования

- Windows 10/11 x64;
- интернет для карты, 3D Земли, поиска и уличных панорам;
- Microsoft Edge WebView2 Runtime — установщик проверяет и ставит его автоматически;
- RTX 3070 не нужна для EXIF/OCR: этот этап работает на CPU и не занимает VRAM.

## Сборка

Установите .NET 10 SDK и workload **.NET desktop development** в Visual Studio.

```powershell
dotnet restore .\EarthExplorer.sln
dotnet build .\EarthExplorer.sln -c Debug
dotnet test .\EarthExplorer.sln -c Release
dotnet run --project .\src\EarthExplorer.App\EarthExplorer.App.csproj
```

Self-contained публикация:

```powershell
.\build-release.ps1 -Runtime win-x64
```

ARM64:

```powershell
.\build-release.ps1 -Runtime win-arm64
```

Результат появится в `dist\ExploreEarth-<version>-portable-<runtime>.zip`. Скрипт также добавит модели `eng` и `rus`, установщики зависимостей и проверит версию EXE. Single-file отключён: Mapsui/SkiaSharp, Tesseract и WebView2 поставляют нативные библиотеки, поэтому папка внутри ZIP надёжнее одного файла.

## Карта, 3D и панорамы

2D-карта использует Mapsui, стандартные тайлы OpenStreetMap и топографический слой OpenTopoMap-R с видимой атрибуцией. 3D Земля работает через CesiumJS и также постоянно показывает атрибуцию OpenStreetMap. Геокодирование выполняет Nominatim. Публичный Nominatim ограничен и не предназначен для автодополнения; клиент отправляет не более одного запроса в секунду и кэширует результаты.

Уличный просмотр использует открытые инстансы Panoramax. Покрытие зависит от фотографий, загруженных участниками, поэтому в некоторых местах снимков может не быть. Спутникового слоя нет: он будет добавлен только с официально разрешённым провайдером.

## Приватность

- EXIF и OCR читаются локально;
- оригинальная фотография не изменяется;
- фотография не отправляется в сеть;
- Nominatim получает только поисковый текст или короткие распознанные строки-кандидаты;
- Panoramax получает выбранные координаты и небольшой bounding box только при поиске ближайшей уличной фотографии;
- настоящие ключи не хранятся в репозитории;
- приложение нельзя использовать для преследования, поиска частного адреса человека, распознавания личности или скрытого отслеживания.

Анализируйте только изображения, на обработку которых у вас есть право.

## Известные ограничения

- 3D Земля использует эллипсоид без детального рельефа и фотограмметрических 3D-зданий;
- покрытие Panoramax не глобальное;
- OCR лучше всего работает по крупным читаемым вывескам; без GPS и текста гипотез может не быть;
- визуальная модель архитектуры и ландшафта ещё не подключена;
- история, метки и настройки SQLite относятся к следующему этапу;
- публичные OSM/Nominatim-сервисы нельзя использовать для массовых запросов;
- WPF собирается только на Windows, поэтому репозиторий содержит Windows CI.
