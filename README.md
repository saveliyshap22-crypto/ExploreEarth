# ExploreEarth

Нативное Windows-приложение для исследования карты Земли, поиска мест и аккуратного определения примерного места съёмки по фотографии.

Это не сайт: интерфейс написан на C#/WPF и запускается обычным `ExploreEarth.exe`. Python, Electron и локальный веб-сервер не требуются.

## Что уже работает

- карта мира с обычным и топографическим слоями;
- поиск городов, адресов и достопримечательностей;
- ввод координат `48.8584, 2.2945` и DMS;
- координаты под курсором и в центре карты;
- метка найденного места;
- светлая и тёмная тема;
- выбор или drag-and-drop фотографии;
- полностью локальное чтение EXIF, включая GPS;
- локальный OCR русского и английского текста;
- до трёх честных гипотез места по EXIF или распознанным надписям;
- режим GeoGuesser с подсказками, метками, расстоянием и очками;
- готовый установщик и portable self-contained `win-x64`;
- автоматическая сборка и тесты на Windows.

Текущий AI-конвейер — это EXIF → локальный Tesseract OCR → поиск распознанных названий через Nominatim. Он не выдаёт гипотезу за точный адрес. Визуальная модель, способная анализировать архитектуру и ландшафт без текста, остаётся следующим этапом.

## Скачать и запустить

Откройте последний успешный запуск **Windows build** в GitHub Actions и скачайте артефакт `ExploreEarth-downloads`. Внутри находятся:

- `ExploreEarth-Setup-win-x64.exe` — рекомендуемый установщик; ставит приложение, OCR-модели и Microsoft Visual C++ Runtime;
- `ExploreEarth-portable-win-x64.zip` — распакуйте папку и запустите `ExploreEarth.exe` без установки.

.NET отдельно устанавливать не нужно: обе сборки self-contained. Windows может показать SmartScreen, пока установщик не подписан коммерческим сертификатом.

## Системные требования

- Windows 10/11 x64;
- для готового установщика и portable-сборки .NET Runtime отдельно не нужен;
- интернет для карты и текстового поиска;
- RTX 3070 не нужна для EXIF/OCR: этот этап работает на CPU и не занимает VRAM.

## Сборка

Установите .NET 10 SDK и workload **.NET desktop development** в Visual Studio.

```powershell
dotnet restore .\EarthExplorer.sln
dotnet build .\EarthExplorer.sln -c Debug
dotnet test .\EarthExplorer.sln -c Release
dotnet run --project .\src\EarthExplorer.App\EarthExplorer.App.csproj
```

Framework-dependent публикация:

```powershell
.\build-release.ps1 -Runtime win-x64 -FrameworkDependent
```

Self-contained публикация:

```powershell
.\build-release.ps1 -Runtime win-x64
```

ARM64:

```powershell
.\build-release.ps1 -Runtime win-arm64
```

Результат появится в `dist\ExploreEarth-portable-<runtime>.zip`. Скрипт также добавит модели `eng` и `rus`. Single-file отключён: Mapsui/SkiaSharp и Tesseract поставляют нативные библиотеки, поэтому папка внутри ZIP надёжнее одного файла.

## Карта и поиск

Карта использует Mapsui, стандартные тайлы OpenStreetMap и топографический слой OpenTopoMap-R с видимой атрибуцией. Геокодирование выполняет Nominatim. Публичный Nominatim ограничен и не предназначен для автодополнения; клиент отправляет не более одного запроса в секунду и кэширует результаты. Для массового публичного релиза нужен собственный или коммерческий endpoint.

Спутникового слоя сейчас нет: он будет добавлен только с официально разрешённым провайдером. Закрытые тайлы и обход ограничений не используются.

## Приватность

- EXIF и OCR читаются локально;
- оригинальная фотография не изменяется;
- фотография не отправляется в сеть; Nominatim получает только короткие распознанные строки-кандидаты;
- настоящие ключи не хранятся в репозитории;
- приложение нельзя использовать для преследования, поиска частного адреса человека, распознавания личности или скрытого отслеживания.

Анализируйте только изображения, на обработку которых у вас есть право.

## Известные ограничения

- OCR лучше всего работает по крупным читаемым вывескам; без GPS и текста гипотез может не быть;
- визуальная модель архитектуры и ландшафта ещё не подключена;
- история, метки и настройки SQLite относятся к этапу 5;
- публичные OSM/Nominatim-сервисы нельзя использовать для массовых запросов;
- WPF собирается только на Windows; поэтому репозиторий содержит Windows CI.
