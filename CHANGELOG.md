# Changelog

## 1.0.0 — 2026-07-14

Первый стабильный выпуск ExploreEarth.

- Добавлен отдельный режим «3D Земля» с атмосферой, освещением и плавной камерой CesiumJS.
- Добавлен перетаскиваемый жёлтый человечек для выбора точки уличного просмотра.
- Подключён поиск открытых панорам и фотографий через федерацию Panoramax.
- Интерактивные панорамы открываются внутри ExploreEarth через WebView2.
- GeoGuessr использует реальные уличные изображения рядом с точкой раунда.
- Работают обычный и топографический слои карты, поиск мест и ввод координат.
- Подключён локальный Tesseract OCR для русского и английского текста.
- Реализованы гипотезы места по EXIF и распознанным географическим надписям.
- Добавлены состояния загрузки и понятная обработка отсутствующего покрытия Panoramax.
- В 3D-режиме сохранена постоянно видимая атрибуция OpenStreetMap.
- Установщик проверяет и при необходимости устанавливает WebView2 Runtime и Microsoft Visual C++ Runtime.
- CI проверяет версию EXE, обязательные файлы, WebView2Loader, OCR-модели, portable ZIP и установщик.

## 0.2.0 — 2026-07-13

- Добавлены верхние режимы «Карта», «Виды карты», `GeoGuesser` и «ИИ по фото».
- Подключён локальный Tesseract OCR для русского и английского текста.
- Реализованы гипотезы места по EXIF и распознанным географическим надписям.
- Добавлен топографический слой OpenTopoMap-R.
- Добавлена GeoGuesser-игра с расстоянием и счётом до 5000 очков.
- CI выпускает self-contained portable ZIP и установщик Inno Setup с OCR-моделями и VC++ Runtime.

## 0.1.0 — 2026-07-13

- Создана модульная архитектура .NET 10/WPF.
- Добавлена карта Mapsui/OpenStreetMap.
- Реализован поиск через Nominatim с ограничением частоты и кэшем.
- Добавлен парсер координат и метка результата.
- Добавлено локальное чтение EXIF и GPS.
- Добавлены темы, базовый ресурсный индикатор, тесты и Windows CI.
